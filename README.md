
# 👤 Dom – Personal Portfolio & Web Project

### 👨‍💻 Built by SereyodamChek

## 📌 About This Project

**Dom** is a **personal portfolio and landing page website** built with HTML, CSS, and vanilla JavaScript.

This project showcases my skills, projects, and creative work through a clean, modern, and responsive design. Featuring smooth animations, interactive elements, and a polished user experience — it serves as both a professional showcase and a playground for frontend experimentation.

🌐 **Live Demo**: [https://v0-new-project-oeabuznqzy2-sereyodam-cheks-projects.vercel.app](https://v0-new-project-oeabuznqzy2-sereyodam-cheks-projects.vercel.app)

---

## 🚀 Key Features

* 🎨 **Modern UI Design** – Clean layout with attention to typography & spacing
* 📱 **Fully Responsive** – Optimized for mobile, tablet & desktop
* 🎬 **Smooth Animations** – CSS transitions & JavaScript interactions
* 🎠 **Slick Carousel** – Interactive image/content sliders
* 🎯 **Font Awesome Icons** – Professional iconography throughout
* ⚡ **Fast & Lightweight** – Vanilla JS with no heavy frameworks

---

## 🛠️ Tech Stack

* 🌐 **HTML5** – Semantic structure & accessible content
* 🎨 **CSS3** – Custom styling, Flexbox/Grid, animations
* ⚡ **Vanilla JavaScript** – Lightweight interactivity & DOM manipulation
* 🎠 **Slick Slider** – Responsive carousel & touch support
* 🎯 **Font Awesome** – Scalable vector icons
* 🌐 **Vercel** – Fast, global deployment & hosting

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/SereyodamChek/dom.git
cd dom
```

### 2. Open in browser

Simply open `index.html` in your preferred web browser:

```bash
# Option 1: Double-click index.html in file explorer
# Option 2: Use a local server for best results

# With Python
python -m http.server 8000

# With Node.js
npx serve .
```

Then visit: [http://localhost:8000](http://localhost:8000)
